# Cursor theme

`Skyrim-by-ru5tyshark-cursors` is a third-party XCursor theme ("Skyrim" by ru5tyshark, sizes 24/32/48/64).
It is not part of Porphyx's own work and is redistributed here as found; no license file came with it.
If the author asks for it to be removed, delete this folder and set `[input.cursor] theme` back to `capitaine-cursors`.
